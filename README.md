# campus-book-trade-system

校园二手书交易与捐赠自提管理系统。

## 项目简介

本项目是数据库系统课程设计项目，围绕校园闲置书籍的出售、捐赠、下单、自提、评价和日志记录等业务展开。当前阶段以数据库设计与 SQL 实现为核心，后续可扩展为带后端接口和前端页面的完整系统。

## 当前已完成

- 需求分析
- 数据需求分析
- E-R 概念模型设计
- 10 张核心数据表设计
- 本地 MySQL 建库建表
- 基础测试数据导入
- 捐赠功能并入 `listing` / `orders`

## 目录结构

- `sql/01_ddl.sql`：建库建表脚本
- `sql/02_dml.sql`：测试数据脚本
- `docs/AI_CONTEXT.md`：给 AI 和协作者的上下文说明
- `docs/FREEZE_RULES.md`：冻结规则，避免误改

## 协作约定

- `main` 分支只保留稳定版本
- 新功能请在功能分支开发后再合并
