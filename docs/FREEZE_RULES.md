# FREEZE_RULES

以下内容已经确定，未经两位组员共同确认不得修改。

## 1. 项目名称

校园二手书交易与捐赠自提管理系统

## 2. 冻结的核心数据结构

- 核心表数量固定为 10 张
- 不新增 `donation` 主表
- 捐赠统一通过 `listing_type` 和 `order_type` 表示

## 3. 已冻结文件

- `sql/01_ddl.sql`
- `sql/02_dml.sql`

## 4. 已冻结业务规则

- `listing.listing_type` 仅区分 `SALE` 和 `DONATION`
- `orders.order_type` 仅区分 `SALE` 和 `DONATION`
- 捐赠订单 `total_amount = 0.00`
- 捐赠业务继续复用订单、自提、评价、日志流程

## 5. 允许修改的内容

- 新增查询脚本
- 新增视图、索引、存储过程、触发器、事务脚本
- 新增部署说明
- 新增前后端代码
- 补充测试数据

## 6. 协作开发规则

- `main` 分支只保留稳定版本
- 每次改动前先拉取最新版本
- 每次完成一个小功能后立即提交
- 合并前先确认是否触及冻结内容
- 若使用 AI 辅助开发，必须先提供本文件与 `docs/AI_CONTEXT.md`
